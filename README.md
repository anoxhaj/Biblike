# Biblike(1.3.0)

A minimalistic offline Bible reading mobile application, built with:

- React Native
- Expo (SDK 55)
- SQLite3

### Features

- Multiple versions
- Cross-references *from* [OpenBibleInfo](https://www.openbible.info/labs/cross-references/)
- Search
- Light/dark mode

### Bible Versions

- Lajmi i Mire 1994 - ALBB (shqip) *from* [BibleGateway](https://www.biblegateway.com/passage/?search=Genesis%201&version=ALB)
- King James 1611 - KJV (english) *from* [BibleGateway](https://www.biblegateway.com/passage/?search=Genesis%201&version=KJV)
