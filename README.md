# Biblike(1.5.1)

A minimalistic offline Bible reading mobile application, built with:

- React Native
- Expo (SDK 57)
- SQLite3

### Features

- Multiple versions
- Cross-references _from_ [OpenBibleInfo](https://www.openbible.info/labs/cross-references/)
- Search
- Light/dark mode

### Bible Versions

- Lajmi i Mire 1994 - ALBB (shqip)
- King James 1611 - KJV (english)
- Giovanni Diodati 1649 - GDB (italiano)
